Light And Shadow

Cards can borrow a quiet environmental field to make subjective material feel situated. The effect should suggest depth and attention, never encode truth, secrecy, or access by itself.

Shed Light

Reveal structure.

Use the lighter side to make a panel feel approachable and readable without turning every surface into a framed object.

Cast Shadow

Hold ambiguity.

Let shade create quiet depth around dossiers, memories, and access paths while the actual state remains explicit in labels and badges.

Vary The Field

Avoid pattern.

Change origin and falloff per layout region so the page feels observed by ambient light instead of stamped with identical gradients.

Theme Semantics

Components should use semantic tokens first, then raw palette tokens only when a visual needs a fixed brand color.
