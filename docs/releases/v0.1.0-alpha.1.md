# Doxvelt v0.1.0-alpha.1

This source-run alpha brings player-directed role-play to the stock DeepSeek
Harness composer and transcript. Choose a character to perform yourself or an
actor to generate their turn. Actor, audience and private direction controls
stay in sync with inline notation. Generated turns land immediately.

Saved episodes reopen from Doxvelt storage. Turn correction and regeneration
create alternate story paths. Body corrections preserve later turns and episode
boundaries. Returning to an original path restores its matching memories.
Memorization remains a deliberate player action. Recollections apply only to
fictionally later episodes and can be inspected.

Follow the [DSH quick start](../../README.md#dsh-alpha-quick-start).
Reverie provides a Windows x64 ZIP. Linux users can build its native engine from
the same tag. The DSH browser flow was exercised on Chrome for Windows.
Doxvelt kernel checks and the legacy workbench build also run in Linux CI.
Scripted provider tests verify routing, audience validation, private context,
memory formation and restart. Live provider behavior and model quality remain
unverified.

The DSH model service supplies model calls. Doxvelt has no direct Pi harness or
agent dependency. DSH's upstream provider package internally uses `pi-ai`.
Actor endpoints must support tool calls with JSON-schema arguments. The
`doxvelt_turn` declaration reports a result for validation and grants no executable
capability. Reflection returns structured JSON through the same DSH service.

## Existing stories and memory

Keep the existing data directory and use the same `--data` path. The launcher
reads its Doxvelt database and memory catalog. When upgrading an older spike
directory it creates a fresh DSH profile; **Open saved episode** restores the
authoritative transcript. There is no transcript schema migration in this release.

Earlier memory publications that exposed non-public character names in speaker
or audience labels are withheld as drifted. Use **Memorize** explicitly on the
selected story path to form a safe replacement. Nothing reforms automatically.
Body corrections similarly withhold affected legacy closure memories and beliefs
on the corrected path, while preserving its later turns and episode boundaries.
Original paths retain their matching memory versions. Drift affects future
episodes; a memory is never injected into its own source episode.

The local Reverie memory catalog is separate from portable simulation archives.
Keep the complete data directory when moving this alpha installation. Do not
assume a simulation archive also carries that catalog or private model settings.

## Current limits

DSH retains stock coding and sign-in controls and the **New Session** sidebar
label. Doxvelt's episode picker is the way to reopen play. Routing prefixes remain
visible in the stock composer; removing one sends the input through ordinary DSH
prompting. Use the Doxvelt controls to keep the selected play mode.

This alpha is local and single-user. It has no hosted accounts, collaboration,
automatic next actor or executable character tools. The earlier Nuxt workbench
remains in the source for authoring and reference.
