# Doxvelt v0.2.0-alpha.1 desktop release candidate

This release replaces the source-run web-alpha installation with a complete
Windows x64 plugin package for the normal DSH desktop application. Publication
is pending review of the Rust migration and packaging PR.

## Player package

Download the release asset `doxvelt-v0.2.0-alpha.1-windows-x64.zip` and its
`.zip.sha256` file. GitHub's automatic source archives are developer downloads.
Extract the complete ZIP, fully quit DSH, and run its `install.ps1` as described
in [README](../../README.md). No Node.js, Bun, Rust, source checkout or separate
Reverie installation is required. DSH supplies its embedded runtime.

The installer verifies all files, installs a versioned user-local copy and uses
DSH's plugin manager to register it. Reinstalling is idempotent. The extracted
download is disposable after installation. When replacing a source-linked
installation, only the old installer's managed Reverie path block is removed;
other profile settings are preserved and the patch file is backed up.

Release metadata records the Doxvelt source commit. Uncommitted development
packages cannot pass the player installer or release verifier.

## Engine and documentation

Rust now owns compilation, immutable simulation history, branch projections,
drafts, source authoring, persistence, archives and Reverie integration. The
maintained API, CLI and DSH entry points do not load the retired TypeScript
kernel/store or Nuxt workbench. DSH continues to supply workspace UI and
credential-owned model calls.

README describes player installation and play. CONTRIBUTING describes source
toolchains, developer linking, validation and reproducible release packaging.
Reverie remains independently versioned and can still be overridden by explicit
deployment configuration.

## Validation and limits

The migration passed all 43 Rust tests and Linux CI's full check. Windows
validation passed 61 focused native, workspace, detached-bundle and real-Reverie
checks. The release verifier checks the ZIP digest, clean provenance, install
and reinstall without Node/Bun/Rust on PATH, rejection of damaged updates,
source editing, manual play, memory formation and later-episode recall.

The actual DSH 0.2.2-rc.3 desktop host also passed the extracted package's browser
flow: activation, source authoring, dated episodes, audience routing, scene
headings, generation, memorization, continued play, process restart and four
viewport sizes. Scripted inference establishes integration behavior, not live
model quality.

The complete Windows JavaScript reference suite still has file-lock/cleanup and
locking-timing failures; one source-save failure in its concurrent run passed
the focused rerun and desktop flow. These results do not establish a fully green
Windows reference suite. Review the PR's latest CI evidence before publication.

This remains an alpha. Back up the complete workspace before upgrading. Portable
simulation archives do not yet include the local Reverie catalog or scene
headings. Other platforms require source builds. DSH preview compatibility is
restricted to the pinned version.
