# Playing Doxvelt

Doxvelt runs inside DeepSeek Harness. Follow [workspace play](WORKSPACES.md) for
installation, authoring, Perform/Generate, revision, episode dates and memory.
Manual Perform needs no model. Generate and Memorize use DSH's configured models.

The legacy separate workbench has been removed. For engineering setup and the
native Rust API, see [the README](../README.md#native-api-and-development) and
[the CLI/API reference](LOCAL_REFERENCE.md).
